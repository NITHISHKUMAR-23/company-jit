1. Description

On the ADSP-21593 and ADSP-SC594 EZKIT, this example blinks LED 7,9,10 on the EV-SOMCRR-EZKIT board and LED 2,4,5 on the EV-21593/SC594-SOM using SoftConfig/GPIO.

On the ADSP-SC598 EZKIT, this example blinks LED 7,9,10 on the EV-SOMCRR-EZKIT board and DS1, DS2 and DS3 on the EV-SC598-SOM using SoftConfig/GPIO.

On the ADSP-21593 and ADSP-SC594 EZLITE, this example blinks DS6, DS7 and DS8 on the EV-SOMCRR-EZLITE board and LED 2,4,5 on the EV-21593/SC594-SOM using SoftConfig/GPIO.

On the ADSP-SC598 EZLITE, this example blinks DS6, DS7 and DS8 on the EV-SOMCRR-EZLITE board and DS1, DS2 and DS3 on the EV-SC598-SOM using SoftConfig/GPIO.

This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.
