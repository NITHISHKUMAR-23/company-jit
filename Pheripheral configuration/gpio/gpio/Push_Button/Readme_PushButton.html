1. Description

This example uses the GPIO service callback method to either Toggle LEDs/print messages when the push buttons are pressed on the ADSP-SC59x EZKIT/EZLITE.
This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

    • 3. Overview

    This example uses the GPIO service to configure the push buttons (GPIO input)and LEDs (GPIO output) on the ADSP-SC59x EZKIT/EZLITE. An interrupt is triggered by the push buttons which executes a callback to toggle the LEDs. The example prompts the user to press both the PB1 and PB2 on the EV-SOMCRR-EZKIT/EV-SOMCRR-EZLITE board of the ADSP-SC59x EZKIT/EZLITE. When each push button is pressed on the ADSP-SC59x EZKIT, a console message is displayed which prints the pushbutton number that is pressed and the LED 7,9,10 on the EV-SOMCRR-EZKIT board of the ADSP-SC59x EZ-Kit will blink for 10 times and stop. When each push button is pressed on the ADSP-SC59x EZLITE, a console message is displayed which prints the pushbutton number that is pressed.

    4. User Configuration Macros
