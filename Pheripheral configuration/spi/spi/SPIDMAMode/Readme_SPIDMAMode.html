1. Description

This example demonstrates transfer of data in DMA mode between different SPI's. SPI transfers in case of DMA mode are non blocking and application can register a callback through which completion of DMA transfer can be tracked. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

    • 3. Overview

    Example opens two SPI instances by default. SPI DMA read/write API's are called after configuring the SPI Clock for communication. After completion of DMA Tx and Rx callback is invoked with a relevant event. After the Tx and Rx completion events Rx Buffer is verified to check if the data received is similar to that of Tx.

    @Note: This example uses List descriptor DMA mode of operation so care must be taken that ADI_PDMA_LISTDESCRIPTOR macro is enabled in adi_pdma_config.h(ADI_PDMA_LISTDESCRIPTOR is enabled by default)

    4. Hardware Setup

    There are external connections which are required in case of this example wherein probing adapter breakout board needs to be sandwiched between carrier and the SOM.

    5. External connections

    As per the example SPI_DEVA is SPI Tx DMA and SPI_DEVB is SPI Rx DMA.

  • By Default: SPI_DEVA = SPI 0 , SPI_DEVB = SPI 1. Connections should be made accordingly

  • SPI0_CLK - Pin 02(P4)
  • SPI0_SEL2 - Pin 06(P4)
  • SPI0_MOSI - Pin 04(P4)
  • SPI0_MISO - Pin 03(P4)

  • SPI1_CLK - Pin 07(P4)
  • SPI1_SS - Pin 10(P4)
  • SPI1_MOSI - Pin 09(P4)
  • SPI1_MISO - Pin 08(P4)

  • SPI_DEVA and SPI_DEVB can be changed to any of the available SPI's i.e. SPI 0/1/2 which can be changed through SPIDMAMode.h

    • @Note: care must be taken that the jumper wires are connected according to the SPI configuration.

    6. User Configuration Macros

    • Enable EV_SOMCRR_EZKIT_SUPPORT in SPIDMAMode.h file to verify the example on EV-SOMCRR-EZKIT
    • Enable EV_SOMCRR_EZLITE_SUPPORT in SPIDMAMode.h file to verify the example on EV-SOMCRR-EZLITE
    @Note: care must be taken that only one of the above macro should be enabled

    7. Pinmuxing

    Following is the pinmux configuration:

    • SPI1 (CLK, MISO, MOSI, SS)
    • SPI0 (CLK, MISO, MOSI, SEL2)
    • GPIO (unavailable) PA06, PA07, PA08, PA10, PA11, PA12, PA13, PA14, PA15, PB05
