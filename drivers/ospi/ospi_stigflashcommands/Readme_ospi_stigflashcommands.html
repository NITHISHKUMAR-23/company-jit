Description

This OSPI driver test example illustrates the use of STIG mode of the OSPI controller to send the most common flash commands and demonstrate how to send any command to the flash using STIG mode. This example is supported on EV-SOMCRR-EZKIT.

The example does follows below steps:

  1. Read Man and Dev ID of the Flash device and compares it with expected values.
  2. Issues Sector Erase command to erase block 0 of Flash.
  3. Read 8 bytes from Flash in STIG mode in Single SPI mode and compares with Erase data.
  4. Set WEL bit in Status register using STIG mode.
  5. Read the WEL bit from status register till WEL is set.
  6. Write 8 Bytes in single SPI mode in STIG mode of controller.
  7. Read 8 Bytes in single SPI mode in STIG mode of controller.
  8. Enter OPI STR mode using STIG command.
  9. Read 8 Bytes in single OPI-STR mode in STIG mode of controller.
  10. Verify the read data.
  11. Reset the flash to exit the OPI-STR mode.
  12. Again read 8 Bytes in single SPI mode in STIG mode of controller and verify the data.

Overview

The example uses the STIG mode to do various flash operations including read and write data to flash memory. Using STIG only 8 data bytes can be read or written to flash at a time

"All Done" printed to the console indicates all the STIG commands were executed successfully.

Other errors are also printed if any of the STIG operation fails in between and the code is terminated.

  2. OSPI_MISO

  7. OSPI_D5
  8. OSPI_D6
  9. OSPI_D7
  10. OSPI_SEL1
