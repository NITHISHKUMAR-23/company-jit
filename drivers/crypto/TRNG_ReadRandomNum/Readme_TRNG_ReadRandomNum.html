1. Description

This example demonstrates generating random numbers using TRNG peripheral. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

    • 3. Overview

    This example demonstrates generating random numbers using TRNG peripheral.
    Two modes are supported. Blocking mode and Non-Blocking mode.
    TRNG can be configured as per static configuration file or can be configured using adi_TRNG_Config()

    The example prints the Random numbers as per the size requested.

    4. User Configuration Macros

    • PERFORM_BLOCKINGMODE (TRNG_ReadRandomNum.h)
      - When this MACRO is configured as (1), then the TRNG driver uses blocking mode API to read random numbers.
    • PERFORM_NONBLOCKINGMODE (TRNG_ReadRandomNum.h)
      - When this MACRO is configured as (1), then the TRNG driver uses non-blocking mode API to read random numbers.
    • USE_STATIC_CONFIG (TRNG_ReadRandomNum.h)
      - When this MACRO is configured as (1), then the TRNG will be configured as per static configuration.
      - When this MACRO is configured as (0), then the TRNG will be configured using adi_TRNG_Config().
