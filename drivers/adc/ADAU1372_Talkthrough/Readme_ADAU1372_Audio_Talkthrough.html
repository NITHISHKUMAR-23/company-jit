1. Description

This example utilizes the ADAU1372 Codec(ADC & DAC) to operate in I2S mode for Audio talkthrough.

This example is supported on EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-SC594
  • ADSP-SC598

3. Tested with

  • EV-SC594-SOM-EZKIT/EV-SC598-SOM-EZKIT
  • EV-SOMCRR-EZLITE
  • Analog Devices CrossCore Embedded Studio
  • ICE-2000

4. Overview

This example demonstrates the usage of ADAU1372 codec(ADC & DAC) and ADSP-SC59x.

The Codec ADAU1372's ADC and DAC are configured in I2S mode.

ADAU1372 Codec is configured to provide clock and frame sync to SPORT4A, SPORT4B of the DSP processor.

5. User Configuration Macros

  1. ADI_CONFIG_CONTINUOUS_AUDIO - This macro is used for selecting continuous time/short time audio as follows

    • ADI_CONFIG_CONTINUOUS_AUDIO : 1 (Continuous Audio playback)
    • ADI_CONFIG_CONTINUOUS_AUDIO : 0 (Audio playback for short duration)


    2. By default audio playback is set to run for short duration(ADI_CONFIG_CONTINUOUS_AUDIO=0).

6. Hardware Setup & External connections

- Connect an audio source i/p to P5.

- Connect a headphone P8 to listen audio o/p.

7. SRU connections

Following connections are done using SRU.
  1. ADAU1372 CODEC Clock (output) ----> SPORT4A clock (input)

  2. ADAU1372 CODEC Frame Sync (output) ----> SPORT4A Frame Sync (input)

  3. ADAU1372 CODEC Clock (output) ----> SPORT4B clock (input)

  4. ADAU1372 CODEC Frame Sync (output) ----> SPORT4B Frame Sync (input)

  5. ADAU1372 CODEC ADC Data (output) ----> SPORT4B D0 (input)

  6. SPORT 4A D0 (output) ----> ADAU1372 CODEC data (input)
