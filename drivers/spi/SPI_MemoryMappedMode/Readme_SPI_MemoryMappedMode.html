1. Description

This feature allows user to directly read content from SPI Flash memory avoiding software bottleneck as there is no need to send opcodes or commands for every access to the Flash memory and hence looks like a read operation from core.

First program the flash memory by running the Flash programmer batch file from the path: C:\Analog Devices\EV-SC59x_EZ-KIT-Relx.x.x\EV-SC59x_EZ-KIT\Examples\drivers\spi\SPI_MemoryMappedMode\scripts\processor\Flash_Programmer This will program a data into flash which will be read back using the memory mapped mode example to verify memory mapped mode read. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

    • 3. Overview

    Memory Mapped mode requires initial configuration in terms of setting up the SPI controller and its memory-mapped header register. Once this is done, all the read accesses are automatically carried out by the controller when the core accesses memory-mapped locations.

    @Note: Only read accesses are supported in memory mapped mode. For programming the flash with instructions or for writing raw data, use the non memory mapped mode mapped mode.

    5. External connections

    6. User Configuration Macros

    • Enable EV_SOMCRR_EZKIT_SUPPORT in SPI_MemoryMappedMode.h file to verify the example on EV-SOMCRR-EZKIT
    • Enable EV_SOMCRR_EZLITE_SUPPORT in SPI_MemoryMappedMode.h file to verify the example on EV-SOMCRR-EZLITE
    @Note: care must be taken that only one of the above macro should be enabled

    7. Pinmuxing

    Following is the pinmux configuration:

    • TWI2 (SCL, SDA)
    • SPI2 (CLK, D2, D3, MISO, MOSI, RDY, SEL1)
    • GPIO(unavailable) (PA00, PA01, PA02, PA03, PA04, PA05, PA14, PA15, PB05)
