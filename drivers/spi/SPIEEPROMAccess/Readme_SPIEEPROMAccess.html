1. Description

This example tests the 1K-bit SPI Serial EEPROM (Microchip 25LC010A) memory device. The Microchip 25LC010A EEPROM is located on the EV-ADSP-SC59x EZ-Kit.PI is used in core mode to access the EEPROM memory. This example is only supported on EV-SOMCRR-EZKIT.

2. Processor

ADSP-SC59x

3. Overview

The Microchip Technology Inc. 25LC010A is a 1 Kbit Serial Electrically Erasable Programmable Read-Only Memory (EEPROM). The memory is accessed via a simple Serial Peripheral Interface (SPI) compatible serial bus.

This example uses the ADSP-SC59x SPI driver to write random data to the EEPROM. The data is then read back and verified.For more information on driver modes of operation please refer to the driver help pages.

6. Software switch settings

The following default EEPROM switch has been set:

  • ~EEPROM_EN set to 1

See ConfigSoftSwitches_EV_21593_SOM.c,ConfigSoftSwitches_EV_SC594_SOM.c, ConfigSoftSwitches_EV_SOMCRR_EZKIT.c for more information.

7. Pinmuxing

Following is the pinmux configuration:

  • SPI0 (CLK, MISO, MOSI)
  • TWI2 (SCL, SDA)
  • GPIO (unavailable): PA06, PA07, PA08, PA14, PA15
