1. Description

This example performs an SPDIF external loopback across the SPDIF co-axial/optical interfaces on the EV-ADSP-SC59x EV-SOMCRR-EZKIT.

This example is supported on EV-SOMCRR-EZKIT.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

3. Tested with

  • EV-21593-SOM-EZKIT/EV-SC594-SOM-EZKIT/EV-SC598-SOM-EZKIT
  • EV-SOMCRR-EZKIT
  • Analog Devices CrossCore Embedded Studio
  • ICE-2000

4. Overview

Example demonstrates the data transfer between SPDIF Tx-Rx in I2S mode.



@Note: This example uses List descriptor DMA mode of operation so care must be taken that

ADI_PDMA_LISTDESCRIPTOR macro is enabled in "adi_pdma_config_2156x.h" (ADI_PDMA_LISTDESCRIPTOR is

enabled by default)

5. User Configuration Macros

  • SPDIF_OPTICAL_TEST : Define this macro to run SPDIF test over Optical cable connectors.

    Undefine this macro to run SPDIF test over Coaxial cable connectors.

6. Hardware Setup

None

7. External connections

  • For SPDIF Digital Test Case :Connect a coaxial cable to the Tx SPDIF and Rx SPDIF coaxial connectors on interface labeled SPDIF IN/OUT (J14).
  • For SPDIF Optical Test Case :Connect a optical cable between the Tx SPDIF(J1) and Rx SPDIF(J2) optical connectors.

8. SRU connections

Following connections are done using SRU.
  1. PCG A Clock Output ----> SPORT0A clock Input

  2. PCG A Frame Sync Output ----> SPORT0A Frame Sync Input

  3. PCG A Clock Output ----> SPDIF0 Tx clock Input

  4. PCG A Frame Sync Output ----> SPDIF0 Tx Frame Sync Input

  5. SPORT0A D0 Output ----> SPDIF0 Tx D0 Input

  6. SPDIF0 Rx Clock Output ----> SPORT0B Clock Input

  7. SPDIF0 Rx Frame Sync Output ----> SPORT0B Frame Sync Input

  8. SPDIF0 Rx D0 Output ----> SPORT0B D0 Input
