1. Description

This example demonstrates how to transfer Tx and Rx EMAC packets in PHY loopback mode using DMA.

2. Processor

  • ADSP-SC594
  • ADSP-SC598

3. Overview

This example demonstrates the usage of Tx and Rx EMAC DMA to transfer the data in PHY loop back mode. The data sent from the MAC to PHY over Tx bus is loopedback inside the PHY and sent back to the MAC over Rx bus. The code can be run for both EMAC0 @ 1000 Mbps and EMAC 1 @ 100 Mbps speed. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE. EV-SOMCRR-EZLITE supports only EMAC0.

Note: For EV-SOMCRR-EZKIT, this example code supports only ADIN1300/ADIN1200 PHYs available on Rev-C version of EV-SOMCRR-EZKIT.

4. Hardware Setup

None

5. Running the Example

  1. Select the EMAC module using macros listed in EMACPhyLoopback.h' file.

    Default setting: EMAC0 .
  2. Build the project, load the executable to the processor, and run it (press resume button in debug view or hit F5).

  3. Look for the debug information displayed on Analog Devices CrossCore Embedded Studio console window.

6. User Configuration Macros

User configuration macros listed in Table 1 are specified in the include file 'EMACPhyLoopback.h'.

Table 1: User Configuration macros
Macro
 Function
EV_SOMCRR_EZKIT_SUPPORT
Enable macro to build example for EV-SOMCRR-EZKIT.
EV_SOMCRR_EZLITE_SUPPORT
Enable macro to build example for EV-SOMCRR-EZLITE.
TEST_EMAC0
Enable macro to build example for EMAC0 @ 1000 Mbps.
TEST_EMAC1
Enable macro to build example for EMAC1 @ 100 Mbps (EV-SOMCRR-EZKIT only).
ENABLE_DEBUG_INFO
 Enable macro to display debug information.

6. Pinmuxing

Following is the pinmux configuration:

  • EMAC0 (All pins)
  • EMAC1 (All pins)
  • TWI2 (SCL-PA14, SDA-PA15)
