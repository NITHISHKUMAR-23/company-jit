1. Description

This example demonstrates transfer of data in between different TWI devices. This is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

3. Tested with

  • EV-21593-SOM-EZKIT/EV-SC594-SOM-EZKIT/EV-SC598-SOM-EZKIT
  • Analog Devices CrossCore Embedded Studio
  • ICE-1000

4. Overview

This example demonstrates an external loopback between TWI2 and TWI1.

At first, TWI2 is configured as Master Tx and TWI1 as Slave Rx.

To change the mode of operation of TWIs, define the "TWI_MODE_CHANGE" in

"TWI_Master_Slave_Mode_Test.h" . This will configure the TWI1 as Master Tx and

TWI2 as slave Rx.

For TWI2 and TWI1 pin muxing is done.



Note:Please connect the jumper wires as mentioned below on EV-SOMCRR-BRKOUT probing adapter board.

5. User Configuration Macros

  • TWI_MODE_CHANGE : To change the TWI mode of operation from Master to Slave & Slave to Master

6. Hardware Setup & External connections

There are external connections which are required in case of this example wherein

EV-SOMCRR-BRKOUT probing adapter board needs to be connected to EV-21593-SOM-EZKIT/EV-SC594-SOM-EZKIT/EV-SC598-SOM-EZKIT



Following connections should be made on EV-SOMCRR-BRKOUT probing adapter board.

TWI2_SCL (Pin 20 in P3) <-----> TWI1_SCL (Pin 18 in P3).

TWI2_SDA (Pin 21 in P3) <-----> TWI1_SDA (Pin 19 in P3).

7. Pin Muxing

TWI1 (SCL,SDA)
TWI2 (SCL,SDA)
