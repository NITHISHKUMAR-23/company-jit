1. Description

This example demonstrates usage of ASRC in TDM8 mode.

This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

4. Overview

    This example demonstrates usage of ASRC in TDM8 mode. For ASRC in TDM8 mode, four ASRC instances are used (ASRC0/1/2/3).

    SPORT0A is configured as input sport and SPORT0B is configured as output sport.

    PCG A is configured for providing clock and frame sync to SPORT0A(input) & ASRC.

    PCG B is configured for providing clock and frame Sync to SPORT0B(output) & ASRC.

    Input Buffer is filled with Sine wave for the Left and Right Channels and the input rate is upconverted or

    downconverted depending on the macro UPCONVERSION by a factor of RATIO(2 by default).



  • To observe the results, application needs to plot the channels.
  • After running the example, The normal word addresses of the input and output buffer will be printed on console window.
  • To observe the two channels (input vs output) , use the following plot configurations : Please note that, the plot needs to be configured after pausing the execution. Upon getting the output on the console, pause the application and then configure plot.

    • Address : Start address of InputBuffer/OutputBuffer. InputBuffer/OutputBuffer can be searched and selected from the addess options as well.

    • Count : (BUFF_SIZE/8)

      Stride : 8,

      Offset : 0(For 1st channel)

                  1(For 2nd channel)

                  2(For 3nd channel)

                  and so on

5. User Configuration Macros

  1. UPCONVERSION - This macro is used for selecting upconversion/downconversion as follows

    Upconversion : 1

    Downconversion : 0

  2. RATIO - This macro is used for selecting the factor for performing the upconversion/downconversion. (it is '2' by default)

8. SRU connections

Following connections are done using SRU.
  1. PCG A Clock (Output) ----> SPORT0A clock (Input)

  2. PCG A Clock (Output) ----> ASRC0 clock (Input)

  3. PCG A Clock (Output) ----> ASRC1 clock (Input)

  4. PCG A Clock (Output) ----> ASRC2 clock (Input)

  5. PCG A Clock (Output) ----> ASRC3 clock (Input)



  6. PCG A Frame Sync (Output) ----> SPORT0A Frame Sync (Input)

  7. PCG A Frame Sync (Output) ----> ASRC0 Frame Sync (Input)

  8. PCG A Frame Sync (Output) ----> ASRC1 Frame Sync (Input)

  9. PCG A Frame Sync (Output) ----> ASRC2 Frame Sync (Input)

  10. PCG A Frame Sync (Output) ----> ASRC3 Frame Sync (Input)



  11. PCG B Clock (Output) ----> SPORT0B clock (Input)

  12. PCG B Clock (Output) ----> ASRC0 clock (Input)

  13. PCG B Clock (Output) ----> ASRC1 clock (Input)

  14. PCG B Clock (Output) ----> ASRC2 clock (Input)

  15. PCG B Clock (Output) ----> ASRC3 clock (Input)



  16. PCG B Frame Sync (Output) ----> SPORT0B Frame Sync (Input)

  17. PCG B Frame Sync (Output) ----> ASRC0 Frame Sync (Input)

  18. PCG B Frame Sync (Output) ----> ASRC1 Frame Sync (Input)

  19. PCG B Frame Sync (Output) ----> ASRC2 Frame Sync (Input)

  20. PCG B Frame Sync (Output) ----> ASRC3 Frame Sync (Input)



    /* Input Data Daisy Chaining */

  21. SPORT0A D0 (output) ----> ASRC0 Dat (input)

  22. ASRC0 TDM (output) ----> ASRC1 Dat (input)

  23. ASRC1 TDM (output) ----> ASRC2 Dat (input)

  24. ASRC2 TDM (output) ----> ASRC3 Dat (input)



    /* Output Data Daisy Chaining */

  25. ASRC0 Dat (output) ----> ASRC1 TDM (input)

  26. ASRC1 Dat (output) ----> ASRC2 TDM (input)

  27. ASRC2 Dat (output) ----> ASRC3 TDM (input)

  28. ASRC3 Dat (output) ----> SPORT0B D0 (input)
