1. Description

This example demonstrates transfer of data in SPORT-I2S mode between different SPORTS which are

enabled together using the Global sport enable feature.

SPORT transfers in case of DMA mode are non blocking and application can register a callback through which completion of DMA transfer can be tracked.

This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

4. Overview

Example demonstrates the data transfer between SPORT0A-0B and SPORT1A-1B in I2S mode.

SPORT0A is configured as Master transmitter and SPORT0B is configured as Slave Receiver. Similarly,

SPORT1A is configured as Master transmitter and SPORT1B is configured as Slave Receiver.

The SPORTs configuration is done using the SPORT static configuration file "adi_sport_config_SC59x.h"



One global group is created of transmitters (SPORT0A & SPORT1A) while another global group is created of receivers(SPORT0B & SPORT1B).

All the four sports in two groups are enabled together using global feature to initiate the transfer at same time.



After completion of DMA Tx and Rx, callback is invoked with a relevant event.

After the Tx and Rx completion events Rx Buffers are verified to check if the data

received is similar to that of Tx.



@Note: This example uses List descriptor DMA mode of operation so care must be taken that

ADI_PDMA_LISTDESCRIPTOR macro is enabled in "adi_pdma_config_2156x.h"(ADI_PDMA_LISTDESCRIPTOR is

enabled by default)

7. SRU connections

Following connections are done using SRU.
  1. SPORT 0A Clock (Master) ----> SPORT0B clock (Slave)

  2. SPORT 0A Frame Sync (Master) ----> SPORT0B Frame Sync (Slave)

  3. SPORT 1A Clock (Master) ----> SPORT1B clock (Slave)

  4. SPORT 1A Frame Sync (Master) ----> SPORT1B Frame Sync (Slave)

  5. SPORT0A D0 ----> SPORT0B D0

  6. SPORT1A D0 ----> SPORT1B D0
