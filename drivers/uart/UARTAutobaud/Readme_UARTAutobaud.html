1. Description

This example uses UART driver to detect the baud rate from a PC connected to the EV-SOM-EZKIT "USB to UART" connector.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

3. Overview

This example demonstrates the usage of baud rate detection automatically using UART to scan the keyboard alphabets and send them onto a Terminal emulator such as TeraTerm to demonstrate UART as a medium to communicate with PC.This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

4. Hardware Setup

None

5. External connections

Connect USB-C cable(For SC598 & SC594 REV-C)/Micro USB cable between the PC and "USB to UART" connector - P2 of EV-21593-SOM/EV-SC594-SOM EZ-Kit or P1 of EV-SC598-SOM 

    On the PC open Control Panel -> Device Manager -> Ports (COM & LPT) to determine which COM port is being
    used by the 'USB Serial Port'. Then open a serial terminal application (for example PuTTY or TeraTerm)
    and configure a serial connection to the COM port with the settings as shown below:
    
    Bits Per second = 9600
    Data bits       = 8
    Parity          = None
    Stop bits       = 1
    Flow Control    = None
    
    Detailed steps for running the above mentioned setup

 1. Open a terminal emulating tool such as tera term on PC and set the baud rate
    at which communication needs to be established.
 
 2. Run the example and enter "@" in the terminal emulator window so that the
    example can detect the baud rate and it will be displayed on the console
    window as  "Detected Baudrate is xx"
  
 3. Any key pressed through keyboard will be displayed on the console window
    and to exit from this program press "Enter"

6. Pinmuxing

Following is the pinmux configuration:

  • UART0 (RX, TX)
  • TWI2 (SCL, SDA)
