1. Description

This example demonstrates transfer of data in DMA mode between different UART's. UART transfers in case of DMA mode are non blocking and application can register a callback through which completion of DMA transfer can be tracked. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

3. Overview

Example opens two UART instances by default. UART DMA read/write API's are called after configuring the Baud rate for communication. After completion of DMA Tx and Rx callback is invoked with a relevant event. After the Tx and Rx completion events Rx Buffer is verified to check if the data received is similar to that of Tx.
@Note: This example uses List descriptor DMA mode of operation so care must be taken that ADI_PDMA_LISTDESCRIPTOR macro is enabled in adi_pdma_config.h(ADI_PDMA_LISTDESCRIPTOR is enabled by default)

4. Hardware Setup

There are external connections which are required in case of this example wherein EV-SOMCRR-BRKOUT probing adapter board needs to be connected to EV-ADSP-21593 or EV-ADSP-SC594 or EV-ADSP-SC598 SOM EZ-KIT.

5. User configuration macros

    UARTDEVA = ADI_UART_0(Default)
    UARTDEVB = ADI_UART_1(Default)
Only one macro should be enabled between STOP_DMA_MODE and LISTDESCRIPTOR_DMA_MODE:
    #define STOP_DMA_MODE
    #define LISTDESCRIPTOR_DMA_MODE

6. External connections

List of UART pins which are available on EV-SOMCRR-BRKOUT probing adapter 

    UART 0 Tx - Pin 22(P3)
    UART 1 Rx - Pin 17(P4)

    As per the example UARTDEVA is UART Tx and UARTDEVB is UART Rx.

    By Default: UARTDEVA = UART 0
                UARTDEVB = UART 1

    @Note: care must be taken that the jumper wires are connected according to the UART configuration.

    As per the configuration, UART 0 configured as Tx should be connected to UART 1 configured as Rx and it is required that a jumper wire needs to be connected between Pin 22(P3) and Pin 17(P4) on EV-SOMCRR-BRKOUT probing adapter.

7. Pinmuxing

Following is the pinmux configuration:

  • UART0 (RX, TX)
  • UART1 (RX, TX)
  • GPIO (unavailable) with ADSP-21593: PA06, PA07, PA14, PA15
  • GPIO (unavailable) with ADSP-SC594: PD08, PD09, PD04, PD05
  • GPIO (unavailable) with ADSP-SC598: PD08, PD09, PD04, PD05
