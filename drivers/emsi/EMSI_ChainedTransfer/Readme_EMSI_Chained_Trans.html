1. Description

In this example 5 transfer operations are submitted together, 1st operation is write to 0th block address, 2nd operation is read from 0th block address, 3rd operation is write to 10th block address, 4th operation is read from 10th block address, 5th operation is read from 12th block address, all transfers will start sequentially once chained adi_emsi_Chained_Transfer() API is called. When all operations get completed application can register a callback.
By default, example opens eMSI instances . The card type is set to eMMC in adi_emsi_Open(). eMMC card identification and configuration of the eMSI Clock (50 MHz for data transfer), data transfer width (8 bit), speed mode (DDR), DMA type (ADMA3), and block length(512 Bytes) for transfers. User submits the various parameter related to each transfer operation, such as

  • NO_OF_BLOCKS: Number block of block size(512 bytes) to be transferred
  • BLOCK_LENGTH: Size of the block (512 bytes) used for upcoming transfer
  • START_ADDRESS_BLOCK: Starting address of sector and byte of the card from where read/write operations should be performed
  • Type of operation: Write or read operation
  • Buffer: Address of the buffer which needs to written to the eMMC device by write operation or filled from eMMC device by using read operation

    • using "ADI_EMSI_CHAIN_TRANSFER_INPUT CHAINED_TRANS_INPUT[]" array. This array is passed into adi_emsi_Chained_Transfer() API .
    Example also shows usage of Auto CMD Auto Select feature which send (CMD23) for predefined multi block transfers and adi_emsi_ControllerRespChek() enables R1 response check by controller for BLOCK_LEN_ ERROR, ADDRESS_MISALIGN,ADDRESS_OUT_OF_RANGE, etc. errors (Please refer to device status section from JEDEC specifications 5.1 for more information). After all transfers are completed, Rx Buffer is verified to check for correct data. All Done! will be printed once all activities completed successfully. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

  • ADSP-SC598

    • 3. Overview

    This example demonstrates non-blocking chained eMSI data transfer using ADMA3 DMA mode for eMMC device. Application can register a callback through which completion of transfer and error during data transfer can be tracked.

    4. User Configuration Macros

  • TxBuffers : Number of transmit buffers.
  • RxBuffers : Number of receive buffers.
  • BLOCK_LENGTH: Size of the block (512 bytes) used for upcoming transfer
  • TOTAL_LENGTHn: Size of each transfer
  • START_ADDRESS_BLOCKn: Starting address of sector and byte of the card from where read/write transfer operations should be performed
  • NO_OF_BLOCKSn: Number block of block size(512 bytes) to be transferred
  • RCA: Relative card address which needs to be assigned to card using CMD3
  • DIVIDER_VALUE: eMSI Clock frequency divider value for data transfers

    • 5. Hardware Setup

    None. This example can be directly run on standalone SC598-SOM board, SC598-SOM board + EV-SOMCRR-EZKIT, SC598-SOM board + EV-SOMCRR-EZLITE.
