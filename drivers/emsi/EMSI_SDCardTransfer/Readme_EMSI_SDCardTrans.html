1. Description

Example opens eMSI instances by default. The card type is set to SD card in adi_emsi_Open() and adi_emsi_SetCardConnector() checks whether card is inserted in socket. eMSI Non-Blocking single block read/write transfer API's are called after SD card identification and configuration of the eMSI Clock (25 MHz for data transfer), data transfer width (4 bit), speed mode (DSSDR), DMA type (ADMA2), block length(512 Bytes) for transfers. After completion of transfers callback is invoked with a relevant event. After the Tx and Rx completion events Rx Buffer is verified to check if the data received is similar to that of Tx. All Done! will be printed once all activities completed successfully. This example is supported on EV-SOMCRR-EZKIT.

2. Processor

  • ADSP-SC598

    • 3. Overview

    This example demonstrates single block non-blocking eMSI data transfer using ADMA2 DMA mode for SD card. Application can register a callback through which completion of transfer and error can be tracked.

    4. User Configuration Macros

  • BLOCK_LENGTH: Size of the block (512 bytes) used for upcoming transfer
  • TOTAL_LENGTH: Size of each transfer
  • START_ADDRESS_BLOCK: Starting address of sector or byte of the card from where read/write transfer operations should be performed
  • NO_OF_BLOCKS: Number block of BLOCK_LENGTH (512 bytes) to be transferred
  • DIVIDER_VALUE: eMSI Clock frequency divider value for data transfers

    • 5. Hardware Setup

    For this example, micro SD card (Version 2.00 and above) should be inserted in SOM-CRR-EZKIT (J9) socket.

    6. External connections

    None.

    7. Pinmuxing

    Following is the pinmux configuration:

    • EMSI0 (CD, CLK, CMD, D0, D1, D2, D3)
    • TWI2 (SCL, SDA)
    • GPIO (unavailable) PA14, PA15, PB15, PD15, PE01, PE06, PE08, PE09, PG01
