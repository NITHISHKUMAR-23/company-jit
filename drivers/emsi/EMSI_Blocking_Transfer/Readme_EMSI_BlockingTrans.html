1. Description

Example opens eMSI instances by default. The card type is set to eMMC in adi_emsi_Open(). eMSI Blocking read/write transfer API's are called after eMMC card identification and configuration of the eMSI Clock (50 MHz for data transfer), data transfer width (8 bit), speed mode (DDR), DMA type (SDMA), Buffer Boundary (4 kB)and block length(512 Bytes) for transfers. The Auto CMD23 feature is enabled to remove overhead of driver issuing CMD23 for pre-defined multiblock transfers. After the read and write transfers are completed, Rx Buffer is verified to check if the data received is similar to that of Tx. All Done! will be printed once all activities completed successfully. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE.

2. Processor

  • ADSP-SC598

    • 3. Overview

    This example demonstrates blocking eMSI data transfer using SDMA DMA mode for eMMC device. Application can register a callback through which error in transfer can be tracked. Example also shows usage of Auto CMD (CMD23) for predefined multi block transfers.

    4. User Configuration Macros

  • BLOCK_LENGTH: Size of the block (512 bytes) used for upcoming transfer
  • TOTAL_LENGTH: Size of each transfer
  • START_ADDRESS_BLOCK: Starting address of sector or byte of the card from where read/write transfer operations should be performed
  • NO_OF_BLOCKS: Number block of BLOCK_LENGTH(512 bytes) to be transferred
  • RCA: Relative card address which needs to be assigned to card using CMD3
  • DIVIDER_VALUE: eMSI Clock frequency divider value for data transfers

    • 5. Hardware Setup

    None. This example can be directly run on standalone SC598-SOM board, SC598-SOM board + EV-SOMCRR-EZKIT, SC598-SOM board + EV-SOMCRR-EZLITE.

    6. External connections

    None.

    7. Pinmuxing

    Following is the pinmux configuration:

    • EMSI0 (CD, CLK, CMD, D0, D1, D2, D3, D4, D5, D6, D7, LED_CONTROL, RST, WP)
    • TWI2 (SCL, SDA)
    • GPIO (unavailable) PA14, PA15, PB15, PC04, PC06, PD15, PE01, PE06, PE08, PE09, PG01, PG02, PG08, PG09, PG10, PI06
