1. Description

This example demonstrates the Stop DMA mode operation of the link port. The linkport 0 is the transmitter and the linkport 1 is the receiver.

2. Processor

    ADSP-21593

    ADSP-SC594

    ADSP-SC598

3. Tested with

  • Analog Devices CrossCore Embedded Studio
  • ICE-2000

4. Overview

In this example,
  • The Linkport uses the OCLK as the clock source from CGU. OCLK of 125 MHz configured from the default preload code.
  • The pinmux is configured to enable both the linkports and TWI2 for softconfig switch.
  • The transmitter, is configured for a Clock value of 15.625 MHz (OCLK/8 ).
  • The LP0 is configured as transmitter in DMA mode. The LP1 is configured as receiver in DMA mode.
  • The 1024 words of data are transmitted from the transmitter to receiver.
  • After the reception is over the buffers are compared to see that the data matches.
Notes: For all the DMA use cases the "adi_pdma_config_2156x.h" should be included in the application under the services->pdma folder. The "ADI_PDMA_LISTDESCRIPTOR" macro should be enabled for all the DMA modes except for Descriptor Array and Descriptor Array on Demand modes.

5. Hardware Setup

On the EZLITE kit connect the link port connectors link port 0 and 1 using the SAMTECH cable.

User Configuration Macros

  • User should only enable either of the one macro mentioned below
  • Enable/Disable TEST_LINKPORT_SDR_8BIT_TRANSFER_MODE
  • Enable/DisableTEST_LINKPORT_SDR_4BIT_TRANSFER_MODE
  • Enable/DisableTEST_LINKPORT_SDR_2BIT_TRANSFER_MODE
  • Enable/DisableTEST_LINKPORT_DDR_4BIT_TRANSFER_MODE
  • Enable/DisableTEST_LINKPORT_DDR_2BIT_TRANSFER_MODE

6. Running the Example

  1. Build the project, load the executable to the processor, and run it (press resume button in debug view or hit F5).

  2. Look for the debug information displayed on Analog Devices CrossCore Embedded Studio console window.
