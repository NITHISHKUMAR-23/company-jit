1. Description

This example demonstrates how to use the DMA driven CRC driver to check whether a memory block is initialized with a particular value.

2. Processor

  • ADSP-21593
  • ADSP-SC594
  • ADSP-SC598

3. Tested with

  • ADSP-21593 EZ-Boards
  • Analog Devices CrossCore Embedded Studio
  • ADDS ICE-2000

4. Overview

This example shows how to use Memory DMA driven CRC device verify a buffer with 32 bit value.
The data buffers to be checked is submitted to the CRC device in memory scan verify mode. the CRC driver kicks-off the memory verification operation. The example validates the interrupt raised by the CRC to check whether memory verification is successful. This example is supported both on EV-SOMCRR-EZKIT and EV-SOMCRR-EZLITE
