Demo Mode REST API documentation

Port number of the API is fixed to 80, and all data (except this documentation) is in json format.

GET <url>/

Demo App.

GET <url>/docs

Get this documentation.

GET <url>/archives

Get all archives and configurations.

GET/PUT <url>/activeArchive

Get or set the current archive and configuration.

GET/PUT <url>/volume

Get or set the current volume. Range 0.0 to 1.0, with 0.0 being muted.
